# Разработка LexPercent Pro

## Структура

- `src/LexPercent.Domain` — данные проекта, событий и подписантов.
- `src/LexPercent.Core` — расчёт decimal и генерация графика.
- `src/LexPercent.Documents` — единая модель справки, PDF и OOXML, сумма прописью.
- `src/LexPercent.Storage` — JSON-проекты, версии, настройки, официальный справочник ЦБ.
- `src/LexPercent.UI` — Windows-интерфейс Avalonia и предварительный просмотр.
- `tests/LexPercent.Tests` — 33 проверки; Fixtures содержит независимые строки согласованной таблицы.
- `installer` — сценарий однофайлового установщика Inno Setup.
- `scripts` — сборка, тесты и упаковка.
- `.github/workflows` — проверка pull request и публикация релиза после слияния в main.

ТЗ: `Specification-v1.1.docx`; соседний TXT предназначен для поиска. Предыдущая редакция хранится в `archive/`. Дополнения после согласования ТЗ отражаются в CHANGELOG.

## Проверка и сборка

Требуется .NET SDK, указанный в global.json. Команды из корня репозитория:

```powershell
./scripts/dev.ps1 build
./scripts/dev.ps1 test
./scripts/dev.ps1 publish
./scripts/package.ps1
```

Для последней команды необходим Inno Setup 6; путь можно передать через `-Compiler`. Приложение публикуется со средой выполнения для Windows x64. Установщик не требует загрузки .NET на компьютере пользователя.

Проверка интерфейса и экспорта без изменения пользовательских проектов:

```powershell
./artifacts/LexPercentPro-win-x64/LexPercentPro.exe --smoke C:/Temp/LexPercentSmoke
```

Параметр `--online` дополнительно проверяет официальный сервис ЦБ. Без него проверка не обращается в Интернет. Результаты записываются в указанный каталог.

## Выпуск

1. Внести изменение в отдельной ветке; добавить содержательные проверки для изменившейся логики.
2. Обновить Version в проекте UI, CHANGELOG и docs/Release-notes.md.
3. Выполнить проверки, открыть PR и дождаться GitHub Actions.
4. После слияния в main Actions создаёт новую версию в Releases с EXE и SHA-256. Существующий релиз не перезаписывается.

Установщик, bin/obj и результаты тестов не коммитятся. Файлы .lpp, настройки и кэш ЦБ пользователя не публикуются. Подписи копируются в проект, поэтому справочник не изменяет сохранённую историю.

Данные ключевой ставки загружаются через HTTPS из KeyRateXML Банка России. Данные должника не передаются. Ошибка обновления не удаляет кэш.
