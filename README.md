# LexPercent Pro

Локальное приложение Windows для расчёта процентов по согласованному ТЗ 1.1.

## Установка одним файлом

Скачайте **LexPercentPro-Setup-0.1.4.exe** из [последнего релиза](https://github.com/skyrunnersochi-afk/LexPercentPro/releases/latest) и запустите его. Установщик создаёт ярлыки, устанавливает все необходимые файлы и добавляет приложение в список установленных программ Windows. Поддерживается Windows 10/11 x64.

## Запуск готовой сборки

Откройте `LexPercentPro.exe` в папке приложения. Установка .NET и Microsoft Office не требуется. Не переносите EXE отдельно: рядом нужны остальные файлы сборки.

При первом запуске заполните организацию, руководителя и папку проектов. Эти сведения можно изменить в «Настройках».

1. Нажмите «Эталон», чтобы открыть согласованный пример Иванова.
2. Для своего расчёта нажмите «Новый» и заполните карточку проекта.
3. Нажмите «Сформировать график». В «Ключевой ставке ЦБ» примените официальный справочник либо введите даты и проценты вручную. Оплаты добавляются в «Событиях».
4. Нажмите «Рассчитать», проверьте интервалы и сохраните проект.
5. В разделе «Документ» выберите справку либо протокол, настройте оформление и экспортируйте результат.

Предварительный просмотр соответствует PDF. Печать открывает PDF в установленной программе просмотра. Word и Excel могут иначе разбивать редактируемые документы на страницы. Для утверждённого вида печати используйте PDF.

## Расчёт и эталон

Начисление учитывается в указанную дату включительно. Оплата уменьшает базу со следующего календарного дня. Переноса выходных нет. Каждая ставка действует со своей даты; повторные ставки на одну дату запрещены. При фиксированной ставке события изменения ставок не участвуют в расчёте.

Используется decimal. Границы календарного года разделяют интервалы; знаменатель 365 либо 366. Округление каждого интервала до копеек — AwayFromZero. Аванс погашает последующие начисления, проценты при отсутствии долга не начисляются.

Согласованный пример: 38 интервалов, 673 дня, проценты **14 393,74 руб.**, основной долг **96 607,59 руб.** Ставки в примере — данные согласованного условия, не автоматически обновляемый справочник.

## Данные и версии

Файл `.lpp` содержит исходные данные, результат и историю. Повторное сохранение без изменений не создаёт версию. Восстановление создаёт новую версию. Копирование создаёт независимый проект с возможностью очистить оплаты.

При перезаписи сохраняется предыдущий файл `.lpp.bak`. Его можно открыть через «Открыть». Автосохранение создаёт отдельный черновик, предлагаемый при следующем запуске. Настройки и черновик находятся в `%LOCALAPPDATA%/LexPercentPro`. Настраиваемый интервал — 1–120 минут. Данные должника и проекта не отправляются в Интернет. Для обновления ставок приложение обращается только к официальному сервису ЦБ РФ.

## Разработка

C# / .NET 10, Avalonia. Модули Domain, Core, Documents, Storage, UI и Tests разделены. Требования: `docs/Specification-v1.1.docx`; доступный поиску текст — соседний `.txt`.

Из PowerShell в корне репозитория:

```powershell
./scripts/dev.ps1 build
./scripts/dev.ps1 test
./scripts/dev.ps1 run
./scripts/dev.ps1 publish
```

Скрипт использует уже установленный SDK в Documents/Codex/Tools/dotnet, либо dotnet из PATH. В VS Code доступны одноимённые задачи. Для восстановления пакетов при разработке нужен Интернет; готовое приложение работает автономно.

Встроенная кнопка «Справка → Тест расчёта» проверяет итог эталона. Полный набор проверок запускается командой test. CSV в Tests/Fixtures извлечён из согласованной пользовательской таблицы и проверяет все 38 интервалов независимо от реализации ядра.

## Обновление ключевой ставки (0.1.2)

Вкладка «История ставок ЦБ РФ» показывает весь официальный справочник по периодам. Кнопка «Обновить ключевую ставку ЦБ РФ» загружает данные немедленно. Автоматическая проверка выполняется при запуске, восстановлении подключения (проверка соединения каждые 30 секунд) и раз в 6 часов работы приложения.

Источник: https://www.cbr.ru/DailyInfoWebServ/DailyInfo.asmx?op=KeyRateXML. Ежедневные записи объединяются в периоды с одинаковым процентом. Вкладка показывает дату обновления и дату последних данных ЦБ.

Справочник сохраняется в `%LOCALAPPDATA%/LexPercentPro/cbr-rates.json`. Ошибка сети не удаляет сохранённые данные. При расчёте нового проекта без вручную введённых ставок используется загруженный справочник. Кнопка «Применить ставки ЦБ к расчёту» заменяет ставки текущего проекта официальными значениями; начисления и оплаты сохраняются. Вручную введённые ставки и согласованный эталон автоматически не заменяются.

## Подписанты (0.1.4)

В «Настройки → Справочник подписантов» добавьте должность с нужными переносами строк, специальное звание, инициалы и фамилию. А.И. Мороз уже включён в справочник.

В карточке расчёта отметьте нужные подписи в блоке «Подписанты справки». Можно выбрать нескольких; порядок соответствует порядку выбора. Если подписанты не выбраны, используется прежнее поле произвольной подписи для совместимости со старыми проектами. Справочник можно редактировать независимо: подписи в сохранённых проектах остаются прежними.

Под цифровой суммой процентов автоматически печатается её сумма прописью, копейки — двумя цифрами. Текст основания выводится с префиксом «Основание:».
